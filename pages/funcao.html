Funções { }

Funções são blocos reutilizáveis de código que realizam tarefas específicas. Elas permitem organizar seu código de forma modular, evitar repetição e tornar seu programa mais legível e mantenível.

Resumo

Uma função é um conjunto de instruções agrupadas que executa uma tarefa ou calcula um valor. Funções podem receber parâmetros (dados de entrada) e retornar um resultado (dado de saída).

Use funções para evitar repetir o mesmo código, organizar lógica complexa e tornar seu programa mais fácil de testar e manter. Uma função deve fazer uma coisa bem - ter um propósito claro e específico.

Tópicos

Uma função é declarada com a palavra-chave function, seguida de um nome, parênteses para parâmetros e um bloco de código entre chaves.

Use return para devolver um valor da função. Após o return, a função interrompe e nenhum código após esta instrução é executado. Você pode chamar uma função quantas vezes quiser pelo seu nome seguido de parênteses.

JavaScript 
function saudar(nome) {
  return "Olá, " + nome;
}

console.log(saudar("Maria")); // "Olá, Maria"

function somar(a, b) {
  return a + b;
}

console.log(somar(5, 3)); // 8
