# JavaScript: Fundamentos e Exemplos

Projeto final desenvolvido durante o curso de desenvolvimento web no **SENAI**.  
Uma base de conhecimento interativa sobre os fundamentos da linguagem JavaScript, com exemplos práticos executáveis diretamente no navegador.

---

## Sobre o projeto

O objetivo é servir como guia de referência rápida para os principais conceitos da linguagem, organizados por tópico e acompanhados de exemplos com laboratório interativo.

---

## Tópicos cobertos

| Tópico | Exemplos |
|---|---|
| Estruturas Condicionais (`if...else`, `switch`) | 4 exemplos |
| Estruturas de Repetição (`for`, `while`, `do...while`) | 6 exemplos |
| Vetores (Arrays) | 2 exemplos |
| Matrizes | 2 exemplos |
| Funções | 2 exemplos |

## Como executar

Por ser um projeto puramente HTML, CSS e JavaScript, **não há dependências ou build necessário**.

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```
2. Abra o arquivo `index.html` diretamente no navegador, ou use a extensão **Live Server** no VS Code para servir localmente.
